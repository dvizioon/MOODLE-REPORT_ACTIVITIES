# Security Policy

## Supported Versions

Security fixes are provided for the current stable release of this plugin.

| Version | Supported |
| ------- | --------- |
| 1.3.x   | Yes       |
| < 1.3   | No        |

This plugin supports Moodle 4.0 to 5.2. Older Moodle branches are out of scope.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security problems.

Report privately by email to: **danielmartinsjob@gmail.com**

Include:

- Plugin version (`version.php` / release tag)
- Moodle version
- Steps to reproduce
- Impact (who can exploit it, what data is affected)

You can expect an initial response within a few business days. If the report is accepted, a fix will be prepared for a new release when possible. If it is declined, you will receive a short explanation.
