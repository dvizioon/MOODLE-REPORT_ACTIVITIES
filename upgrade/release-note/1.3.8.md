## Release notes

report_activities 1.3.8 (build 2026110700)
Requires Moodle 4.0+. Supported: Moodle 4.0 to 5.2. Maturity: Stable.

Adds two Report Builder data sources for custom grade reports (columns, filters, conditions, audiences, schedules and CSV/Excel export stay in Moodle core).

Sources:
1. Activities: one row per student and graded activity.
2. Final grade: one row per student and course total (same value as Course total in the grader report).

Use Activities for grades per activity. Use Final grade for the course total only.

Access requires the capability report/activities:view. The plugin does not store personal data of its own.

Changes in 1.3.8:
- Support for Moodle 4.0 through 5.2 in one package
- Removed the redundant Site administration / Reports menu entry
- Continuous integration and documentation updates

Install into report/activities/ (Moodle 4.x) or public/report/activities/ (Moodle 5.1+), then run site upgrade.

## Privacy

This plugin does not store personal data of its own. It only reads existing Moodle data (users, courses, and gradebook grades) to show them in Report Builder reports. No extra personal information is saved by the plugin.
