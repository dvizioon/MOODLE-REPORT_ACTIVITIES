## Release notes

Copy everything below this line into **Release notes**:

```text
report_activities 1.3.8 (build 2026110700)
Requires Moodle 4.0+. Supported: Moodle 4.0 to 5.2. Maturity: Stable.

This plugin does not add a separate report screen. It registers two Report Builder data sources so you can build custom reports with columns, filters, conditions, audiences, schedules and CSV/Excel export.

Report sources
1) Activities — one row per student × graded activity (gradebook itemtype = mod). Fields: user, course, course category (Moodle 4.1+), activity name/type, raw grade, final grade, percentage, grade 0–10, feedback, last modified.
2) Final grade — one row per student × course total (itemtype = course), via grade_get_course_grades(). Same value as Course total in the grader report.

Use Activities for per-activity grades. Use Final grade for the course total only.

Access: capability report/activities:view (system context). Privacy: null provider (reads core tables only).

Changes in 1.3.8
- Declared support for Moodle 4.0 through 5.2 in one codebase
- Compatibility layer for Report Builder APIs across Moodle 4.0–5.2
- Removed the redundant Site administration / Reports menu entry (it only redirected to Report Builder)
- GitHub Actions CI: Moodle 5.2 gate (PostgreSQL + MariaDB), compatibility matrix 4.0–5.2, security scan
- PHPUnit bridge and PHPCS fixes for CI across supported branches
- Documentation and screenshots updated; wiki in English and Portuguese

Install path: report/activities/ (Moodle 4.x) or public/report/activities/ (Moodle 5.1+). Run site upgrade after install. No database tables are created or changed in this release.
```
