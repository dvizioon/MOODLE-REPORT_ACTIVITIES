# Compatibilidade

## Declaração oficial

| Campo | Valor |
|-------|-------|
| Versão mínima do Moodle | 4.0.0 |
| Intervalo suportado | 4.0 a 5.2 |
| Versão do plugin | 1.3.8 |
| Build | 2026110500 |

## Matriz por versão

| Moodle | Observação |
|--------|------------|
| 4.0 | Fontes Atividades e Nota final. Sem campo de categoria do curso. |
| 4.1 a 4.4 | Ambas as fontes, incluindo categoria do curso. |
| 4.5 | Ambas as fontes. |
| 5.0 e 5.1 | Ambas as fontes. |
| 5.2 | Ambas as fontes. Versão de referência para validação. |

## Versões não suportadas

O Moodle 3.x não é suportado, pois o Construtor de Relatórios não está disponível nessas versões.

## Código unificado

A partir da versão 1.3.8, o mesmo pacote atende Moodle 4.0 a 5.2, com camada de compatibilidade para as APIs do Report Builder em cada geração.
