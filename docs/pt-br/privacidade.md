# Privacidade

[Índice](index) · [English](../en/privacy)

## Declaração

O plugin utiliza um provedor de privacidade nulo (`null provider`).

Implicações:

- Não cria tabelas próprias com dados pessoais
- Não armazena cópias de usuários, cursos ou notas
- Apenas lê dados já existentes no Moodle (usuários, cursos e caderno de notas) por meio do Construtor de Relatórios

## Controle de acesso

A exibição das fontes depende da capacidade `report/activities:view`. Sem essa permissão, as fontes não aparecem para o usuário.

## Conformidade

Para políticas internas (LGPD, GDPR ou equivalentes), o plugin deve ser tratado como componente de **apresentação** de dados já mantidos pelo Moodle, sujeito às mesmas regras de papéis, retenção e acesso do site.
