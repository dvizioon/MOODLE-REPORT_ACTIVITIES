# Report Activities (Português)

[English](../en/index) · [Home](../Home)

Documentação do plugin Moodle **Report Activities** (`report_activities`).

O plugin integra-se ao **Construtor de Relatórios** (Report Builder) e disponibiliza fontes de dados de notas para a criação de relatórios personalizados.
