# Compatibility

[Index](index) · [Português](../pt-br/compatibilidade)

## Official declaration

| Field | Value |
|-------|-------|
| Minimum Moodle version | 4.0.0 |
| Supported range | 4.0 to 5.2 |
| Plugin version | 1.3.8 |
| Build | 2026110500 |

## Matrix by version

| Moodle | Notes |
|--------|-------|
| 4.0 | Activities and Final grade sources. No course category field. |
| 4.1 to 4.4 | Both sources, including course category. |
| 4.5 | Both sources. |
| 5.0 and 5.1 | Both sources. |
| 5.2 | Both sources. Reference version for validation. |

## Unsupported versions

Moodle 3.x is not supported because Report Builder is not available on those versions.

## Unified codebase

From version 1.3.8, the same package supports Moodle 4.0 to 5.2, with a compatibility layer for Report Builder APIs across those releases.
